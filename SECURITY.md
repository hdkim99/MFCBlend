# Security policy

Please report security vulnerabilities privately through GitHub's private
vulnerability reporting interface when available. Do not include cylinder
certificates, confidential formulations, plant details, credentials, or
unpublished research data in public issues.

MFCBlend is a calculation aid, not a process-safety tool. It does not evaluate
flammability, explosion limits, reactivity, material compatibility, ventilation,
purging, or regulatory compliance. A mathematically exact result is not an
authorization to apply MFC setpoints.

Persistent self-hosted CI runs only on pushes by trusted maintainers, manual
dispatches, and owner-authored same-repository pull requests. External fork code
is not checked out or executed on the DGX host.
